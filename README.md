# ☕ AI Coffee Ordering App

A modern Android application built with **Kotlin** and **Jetpack Compose** that provides an interactive coffee ordering experience. Users can browse coffee categories, explore coffee details, manage favorites, add items to a cart, choose payment methods, and receive AI-inspired coffee recommendations through a clean and modern interface.

---

## ✨ Features

### 🤖 AI Coffee Suggestion Screen

An AI-inspired recommendation section that helps users discover different coffee options directly from the home screen.

* Interactive recommendation experience
* Modern AI-themed UI
* Easy access from the home screen

---

### ☕ Category Filtering

Browse coffee products based on categories.

Available Categories:

* All Coffees
* Espresso
* Cappuccino
* Latte
* Macchiato
* Americano
* Mocha

---

### 📖 Coffee Details Screen

View detailed information about each coffee product.

Features:

* Coffee image
* Product description
* Price display
* Size selection
* Favorite option
* Add to Cart functionality

---

### ❤️ Favorites Management

Save and manage favorite coffee products.

Features:

* Add products to favorites
* Remove products from favorites
* Dedicated favorites screen

---

### 🛒 Cart Management

Manage selected coffee items before placing an order.

Features:

* Add products to cart
* Increase quantity
* Decrease quantity
* Dynamic total calculation
* Order summary

---

### 🔢 Quantity Controls

Modify product quantities directly from the cart screen.

Features:

* Increase quantity
* Decrease quantity
* Automatic price updates

---

### 💳 Payment Method Selection

Flexible payment options during checkout.

Supported Methods:

* Online Payment
* Cash On Delivery

---

### 🧭 Multi-Screen Navigation

Smooth navigation between different sections of the application.

Screens:

* Welcome Screen
* Home Screen
* Coffee Details Screen
* Favorites Screen
* Cart Screen
* Profile Screen

---

### 🎨 Modern Jetpack Compose UI

Built using modern Android UI development practices.

Highlights:

* Material 3 Design
* Responsive Layouts
* Reusable Components
* Clean User Experience
* Coffee-Themed Design
